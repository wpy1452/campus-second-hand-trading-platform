# 校园二手交易平台可行性分析

## 一、技术栈与可行性分析

### 1. 技术选型
*   **用什么技术**：JavaSE、MySQL(JDBC)、Maven、Swing、多线程、Git
*   **界面用什么**：Swing 做桌面 GUI 窗口，包括登录、注册、主窗口、商品列表、商品详情、发布商品、个人中心、聊天窗口、交易界面等。用 JTable 展示商品、交易、留言等数据，用 ActionListener 处理按钮事件，用 JFrame、JPanel 等完成界面布局。
*   **数据存取用什么**：远程 MySQL 数据库加 JDBC。编写 DBUtil 工具类封装连接和关闭资源，所有 SQL 用 PreparedStatement 预编译执行，完成增删改查。
*   **通信用什么**：JDBC 直连（基于 TCP/IP 的数据库通信）。
*   **项目构建用什么**：Maven 管理依赖和构建，配置简单，便于小组统一开发环境。

### 2. 可行性评估
*   **JavaSE**：全员有基础，可以完成基本类、集合、IO、多线程等内容。
*   **Swing**：目前 0 人掌握，但现在安排学习来得及，要求小组一半及以上成员掌握。先做登录、主窗口、商品列表等简单界面，再逐步完善聊天和交易界面。
*   **MySQL**：3 人掌握，现要求全员学习，掌握建表、增删改查、JDBC 连接流程。
*   **JDBC**：需要学习 DBUtil、PreparedStatement、结果集封装等，难度不大，可边做边学。
*   **Maven**：配置简单，半天即可掌握基本命令和依赖管理。

## 二、功能列举

*   **用户模块**：注册、登录、好友添加/好友列表、个人信息修改、密码修改。
*   **首页/商品模块**：展示商品信息、浏览商品列表、查看商品详情、发布商品、修改商品、下架商品、删除商品、我的商品管理。
*   **商品状态管理**：在售、已售出、已下架等状态显示与管理。
*   **搜索模块**：输入关键字搜索是否有相关物品，并展示搜索结果。
*   **聊天模块**：单聊。客户端可以监听消息、发送消息、显示聊天记录。
*   **交易模块**：点击商品或链接进入交易界面，根据情况显示已完成、未支付、取消、退货等状态；支持创建、推送、取消商品交易。
*   **留言模块**：商品留言、查看留言列表、我的留言管理。

## 三、数据和逻辑

### 数据

创建实体类：用户 User、商品 Goods、留言 Message、聊天 Chat、交易 Trade。

数据库设计 5 张数据表：

| 表名          | 存储字段说明                                                 |
| :------------ | :----------------------------------------------------------- |
| **user表**    | 存储用户编号、账号密码、昵称、联系信息                       |
| **goods表**   | 存储商品编号、卖家编号、标题、详情描述、价格、图片路径、商品状态、发布时间 |
| **Message表** | 存储留言编号、关联商品编号、留言人编号、留言内容、留言时间   |
| **chat表**    | 存储聊天编号、关联商品编号、发送人编号、接收人编号、聊天内容、发送时间 |
| **trade表**   | 存储交易编号、对应商品编号、买卖双方编号、交易金额、交易状态、创建时间 |

### 逻辑

程序直接通过 JDBC 操作本地 MySQL 数据库。

核心业务流程：

1. **登录**：录入账号密码，与用户表比对校验，验证成功进入系统主界面。
2. **注册**：录入账号密码及基本信息，校验账号是否重复，封装为 User 对象存入用户表，提示注册成功并跳转至登录界面。
3. **发布商品**：填写商品信息并做简单校验，封装为对象存入商品表，刷新界面展示最新商品。
4. **浏览商品**：读取数据库中在售商品，加载到界面表格，点击条目打开商品详情页。
5. **商品搜索**：接收用户输入关键词，对商品表执行条件查询，展示匹配结果。
6. **聊天操作**：填写聊天内容，保存至聊天数据表，接收端利用 `Swing Timer` 配合 `SwingWorker` 多线程定时轮询（每3秒）数据库中的未读记录，查到后追加到界面并标记为已读，实现准实时消息刷新。
7. **个人商品管理**：根据当前登录用户编号，查询该用户全部商品，在界面完成下架、删除操作。
8. **交易流程**：选定商品创建交易记录存入交易表，同步更新商品状态，界面展示对应交易状态。
9. **留言流程**：在商品详情页输入留言内容，封装为 Message 对象，JDBC 插入 message 表，刷新当前商品留言区展示最新留言。
