# 二手物品交易平台需求文档

## 1 项目简介

这是一个桌面版的二手物品交易软件，主要用来做闲置物品的流转。用户注册登录之后，可以发布自己的二手东西，浏览别人的商品，给商品留言，和卖家聊天沟通，还能创建交易记录管理买卖状态。

整个项目使用 JavaSE 做业务，Swing 写桌面窗口，MySQL 存数据，JDBC 操作数据库，Maven 管理项目依赖，Git 用来团队代码管理。

## 2 系统要实现的目标

1. 用户可以注册账号、登录系统，修改个人信息和密码，管理好友
2. 用户可以发布、查看、修改、下架、删除自己的二手商品
3. 能够搜索想要的商品，点开看商品完整详情
4. 可以在商品下面写留言，查看所有留言
5. 买卖双方可以一对一聊天沟通
6. 能够发起交易，查看不同的交易状态，支持取消交易

## 4 数据需求

系统一共保存五类核心数据。

| 数据类别 | 包含字段 |
| --- | --- |
| 用户数据 | 用户编号、账号、密码、昵称、联系方式 |
| 商品数据 | 商品编号、卖家编号、标题、描述、价格、图片路径、商品状态、发布时间 |
| 留言数据 | 留言编号、关联的商品编号、留言人编号、留言内容、留言时间 |
| 聊天消息数据 | 聊天编号、关联商品编号、发送人编号、接收人编号、聊天内容、发送时间 |
| 交易数据 | 交易编号、商品编号、买方编号、卖方编号、交易金额、交易状态、创建时间 |

## 6 需要做的界面窗口

- **登录窗口**：用来输入账号密码登录系统。
- **注册窗口**：新用户填写信息注册账号。
- **主窗口**：软件首页，展示商品列表，有搜索和各个功能的入口。
- **商品详情窗口**：看商品详细信息以及留言。
- **发布商品窗口**：填写信息发布二手商品。
- **个人中心窗口**：修改个人资料、改密码、看好友列表、管理自己发布的商品。
- **聊天窗口**：双方一对一对话。
- **交易窗口**：发起交易，查看当前交易的状态。

## 7 技术说明

- **JavaSE**：写项目业务逻辑，处理集合、多线程这些功能。
- **Swing**：开发所有桌面窗口，处理按钮点击事件，展示列表数据。
- **MySQL**：存放系统全部数据。
- **JDBC**：写一个 DBUtil 工具类连接和关闭数据库，使用 PreparedStatement 执行增删改查。
- **Maven**：管理项目依赖，统一小组开发环境。
- **Git**：团队代码版本控制。

## 8 核心业务流程

### 登录流程

1. 打开登录窗口
2. 输入账号密码
3. 查询数据库校验账号密码
4. 校验通过，打开主界面；校验失败弹出错误提示

### 注册流程

1. 打开注册窗口，填写注册信息
2. 判断账号是否已经存在
3. 账号不存在就保存用户信息到数据库
4. 提示注册成功，跳转到登录窗口

### 发布商品流程

1. 打开发布商品窗口，填好商品信息
2. 简单校验信息不为空
3. 将商品信息存入数据库
4. 首页刷新，显示刚发布的商品

### 聊天流程

1. 打开聊天窗口
2. 用户输入消息点击发送，消息存入数据库
3. 接收方程序每 3 秒查询一次数据库的新消息
4. 获取到消息，展示在聊天界面上

### 交易流程

1. 用户选择商品发起交易
2. 创建交易记录保存到数据库
3. 更新对应商品的状态
4. 在交易界面查看当前交易状态

## 功能优先级

### 必须实现

1. 用户注册
2. 用户登录
3. 商品列表浏览
4. 查看商品详情
5. 发布商品
6. 我的商品管理：修改、下架、删除本人商品
7. 商品关键词搜索
8. 商品留言、查看商品留言
9. 数据库五张基础表，DBUtil 工具类，JDBC 增删改查
10. 基础界面：登录窗口、注册窗口、主窗口、商品详情窗口、发布商品窗口

### 建议实现

1. 修改个人信息
2. 修改登录密码
3. 一对一聊天（数据库轮询方式收发消息、查看聊天历史）
4. 交易创建、查看交易状态、取消交易
5. 个人中心窗口、聊天窗口、交易窗口
6. 商品状态管理：在售、已售出、已下架状态切换与页面显示

### 可实现

1. 添加好友
2. 查看好友列表
3. 我的留言管理，查看自己全部历史留言

### 功能拓展

1. 图片处理优化：不再手动填写图片路径，弹窗选择本地图片，程序自动保存图片文件。
2. 商品分类：给商品增加类别，例如书籍、数码、衣物，支持按分类筛选商品。
3. 商品收藏功能：用户可以收藏商品，个人中心查看收藏列表。
4. 交易完善：新增确认收货操作；交易结束后买家可以对卖家写评价。
5. 新消息提醒：收到聊天消息弹出提示，不用停留在聊天窗口。
6. 分页功能：商品过多时分页加载，避免界面卡顿。
7. 密码加密：数据库不再明文存储用户密码，提升安全性。
8. 交易记录导出：把个人交易记录导出为 txt 文件保存到本地电脑。
9. 拉黑用户功能：拉黑某人之后，接收不到对方聊天消息。
10. 简易管理员模块：管理员账号，可以查看全部用户、下架违规商品、删除不当留言。
